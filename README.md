# Overview

This is a course to teach others about Object-Oriented Programming using Python. The course is designed to be taught in five different sessions:

#### Session 1:

* Introductory Presentation
* Assign Project Part 1
* Start `demo`

#### Session 2:

* Continue `demo`

#### Session 3:

* Continue `demo`
* Assign Project Part 2

#### Session 4:

* Finish `demo`

#### Session 5:

* Collect Project submissions
* No lecture held unless some material has not been covered yet

Each directory contains its own README file for further elaboration. Brief descriptions for each section are contained here.

# Project

The project for this course will have students create animations of stick figures using a Procedural Approach in Part 1 and an Object-Oriented Approach in Part 2.

Modules, examples, and handouts are provided for each part of the project.

# Demo

This demo progressively demonstrates how to utilize Python for Object-Oriented Programming while demontrating the use of the Four Principles:

* Encapsulation
* Abstraction
* Inheritance
* Polymorphism
